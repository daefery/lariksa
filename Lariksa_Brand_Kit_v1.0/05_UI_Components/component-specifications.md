# Lariksa component specifications (concept)

## Buttons
- Height: 40-44 px; padding: 12-18px; radius: 10px. Primary Forest Ink on white; accent lime with dark ink.
- Required states: default, hover, pressed, focus-visible, disabled, loading.

## Inputs
- Radius 10px; 1px border #DDE4DA; comfortable touch area >=44px; visible label and validation message.

## Note cards
- Radius 16px; 24px padding; 1px subtle border; use line-clamped preview where appropriate.

## Layout
- Editor max width 720px; sidebar 256px; 8px rhythm with 4px micro adjustments.
- Mobile: hide/collapse sidebar and present a single writing column.

## Accessibility
- Assess WCAG 2.2 AA color contrast per usage and state; keyboard-first interaction; proper focus management; reduced motion.
- Semantic colors are illustrative and require accessible pairings before shipment.

## Motion
- 140ms controls / 220ms panels, ease-out; avoid animations while typing.
