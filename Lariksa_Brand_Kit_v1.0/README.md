# Lariksa - Brand Identity Kit v1.0

**Creative direction:** Quiet Intelligence
**Tagline:** Make room for every thought.
**Roots:** Invented name inspired by Indonesian *larik* (a line of writing).

## Included
01. PDF brand guideline (positioning, visuals, typography, voice, implementation)
02. Editable SVG logos and rendered PNG versions
03. App icon previews, favicon .svg/.ico and export guidance
04. JSON tokens, CSS variables and Tailwind example
05. Interactive offline-capable UI HTML concept with light/dark toggle and component specifications (web font may require network; fallback works offline)
06. Social hero artwork in SVG and PNG, copy template
07. Brand voice and EN/ID UI localization examples
08. Pre-launch clearance and legal handoff checklist

## Use
- Open `01_Brand_Guidelines/Lariksa_Brand_Guidelines.pdf` first.
- Open `05_UI_Components/workspace-preview.html` in a browser to view the UI concept.
- Edit `.svg` assets in Figma, Illustrator, or Inkscape.
- Import `04_Design_Tokens/theme.css` into a web prototype.

## Important notes
All files are a **proposed** brand system; neither Lariksa naming nor mark is legally cleared. No font binaries are included. Logo lockup uses a system-font approximation, **not** a custom trademark-ready lettering design. For final wordmarks, redraw lettering in vector outlines.
