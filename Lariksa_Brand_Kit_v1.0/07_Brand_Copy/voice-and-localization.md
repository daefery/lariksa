# Voice and localization

Personality: thoughtful, warm, precise, quietly confident.

Do: Use plain verbs, short supportive sentences, clear recovery paths, and welcoming empty states.
Don't: Overpromise, use AI jargon as a selling point, or use overly technical error strings.

| Context | English | Bahasa Indonesia |
|---|---|---|
| CTA | Capture a thought | Catat ide |
| New item | New note | Catatan baru |
| Empty state | A fresh page for your next idea. | Halaman baru untuk ide berikutnya. |
| Saved | All changes saved | Semua perubahan tersimpan |
| Search | Search your thoughts | Cari catatanmu |
| Error | We couldn't save this yet. Try again. | Catatan belum berhasil disimpan. Coba lagi. |

Translations are editorial starting points; have native speakers review for final product context.
